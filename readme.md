## My solutions to [Advent of Code 2025](https://adventofcode.com/). 

Work in progress. My solutions are written in Python and Jupyter notebooks.

I'm using uv as a package manager for Python modules, which are listed in the *pyproject.toml* file.

## How to run

1. Install [uv](https://docs.astral.sh/uv/getting-started/installation/).
2. Clone this repo and install dependencies:
   ```
   git clone https://github.com/<your-username>/adventofcode-2025.git
   cd adventofcode-2025
   uv sync
   ```
3. Run the notebooks with Jupyter:
   ```
   uv run jupyter notebook
   ```
   This opens a file browser where you can select any notebook (e.g. `aa_day9.ipynb`) to run.

   Alternatively, open the notebooks directly in VS Code with the Jupyter extension — select the `.venv` Python interpreter when prompted.
